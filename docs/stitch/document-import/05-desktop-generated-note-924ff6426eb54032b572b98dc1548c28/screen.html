Working Memory & The Central Executive

stars Score: 92%
schedule Last reviewed 2m ago

article Conceptual Summary

AI REFINED

The central executive serves as the attentional controller of Baddeley's working memory model. Its primary function is not storage, but the coordination of slave systems like the phonological loop and visuospatial sketchpad.

You initially noted it had "infinite capacity," but recall research suggests it is actually strictly limited in capacity. It handles processing-heavy tasks such as mental arithmetic and multitasking by selectively focusing on relevant stimuli while inhibiting distractions.

Critical Terms

Phonological Loop

The component that deals with spoken and written material, divided into the phonological store and articulatory process.

Visuospatial Sketchpad error

Inner eye: stores visual and spatial information. (You missed the "Inner Scribe" subcomponent)

Episodic Buffer

Acts as a 'backup' store which communicates with both long-term memory and working memory components.

Attentional Capacity

The total amount of cognitive resources available for a task at any given time.
